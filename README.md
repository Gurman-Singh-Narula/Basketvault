# BasketVault - Sneaker Authentication Platform



## 📝 Description

BasketVault is a web-based platform that helps users verify the authenticity of premium sneakers. With the rise of counterfeit sneakers in the market, BasketVault uses cutting-edge technology to provide reliable authentication services, ensuring collectors and enthusiasts can buy with confidence.

## ✨ Features

- **Sneaker Authentication**: Verify sneakers using unique codes or QR scanning
- **Sneaker Showcase**: Browse featured and new premium sneakers
- **Responsive Design**: Optimized for all devices and screen sizes
- **User-friendly Interface**: Modern and intuitive design for seamless user experience
- **Product Details**: Comprehensive information about each sneaker model
- **Newsletter Subscription**: Stay updated with the latest drops and authentication tips

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection for font loading and API calls

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Gurman-Singh-Narula/basketvault.git
   ```

2. Navigate to the project directory
   ```bash
   cd basketvault
   ```

3. Open `index.html` in your browser
   ```bash
   # On Windows
   start index.html
   
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   ```
